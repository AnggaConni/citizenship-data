FAO FISHSTAT
Open official FAO source ↗
FAO country-year series is refreshed by the repository's scheduled data workflow.

Series unit: tonnes live weight. The national total is aggregated from source rows; if components carry different FAO flags, the table shows the union of those flags without claiming they apply to every component. Flag codes are displayed as supplied, not decoded by this app; consult FAO's release metadata for their meanings. Production volume is not consumption, household food security, fish-stock health, or proof of sustainable fishing.

4 RESEARCH APIs
Europe PMC connection

Uses the public Europe PMC REST search API directly; no API key or proxy deployment is required. Europe PMC is strongest for life-sciences literature, so coverage is narrower for general policy and governance research.

Public REST API · Up to 8 papers per query · search terms are broadened across comma-separated topics.
OpenAlex provides semantic similarity; Crossref provides publication metadata; Europe PMC adds life-sciences literature; OpenAIRE adds research-graph records. Results are deduplicated where possible. Relevance, citation counts, and open-access labels do not establish methodological quality or policy applicability. Review each original source.
Search OpenAlex, Crossref, Europe PMC and OpenAIRE in parallel. Results from available providers will be retained even if one provider is unavailable.

Data sources and methods
Biosphere reserves: UNESCO MAB dataset (mab001) · Global geoparks: UNESCO Global Geoparks (eg0001) · Marine indicators: Marine Biodiversity by Ocean Area (ioc001) · Marine occurrences: OBIS · Hydrology: Open-Meteo Flood API / GloFAS · Water indicators: World Bank / FAO AQUASTAT · Climate: NASA POWER · Publications: OpenAlex, Europe PMC, Crossref and OpenAIRE Graph · Institutions: ROR.
How to interpret recommendations
Results are selected by semantic similarity to a user-written question. The tool does not generate a scientific consensus, assess all methodological quality, or guarantee that an article is open access. Some metadata or links may be missing.
Independent exploratory prototype; not an official institutional product or endorsement. Dataset records, photographs, article metadata and map tiles retain their own licences and attribution requirements. The marine indicator source contains fields derived from other datasets; this page intentionally omits IUCN-threatened-species fields while that source component's provenance and reuse requirements are not separately assessed. Maps show source points or representative coordinates only—not official boundaries. © OpenStreetMap contributors. View source code.

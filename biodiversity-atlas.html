Biodiversity Atlas.

Explore country-level biodiversity data already prepared by the Python pipeline—without opening the pipeline code. Inspect georeferenced occurrence samples, browse individual records, and compare them with a sample-density grid. This first release starts with Indonesia.

01 Indonesia pilot dataset GBIF occurrence records UNESCO MAB reserve points, when available Open, interactive map
⚠

Important: this is a sample, not a complete biodiversity inventory

The Indonesia file currently contains a capped sample of georeferenced GBIF occurrence records. A sample point marks a documented record, not an entire species range or proof of current presence. Grid cells summarise only the records collected for this sample. This independent prototype is not an official GBIF, UNESCO or IUCN product. Third-party data retains its own licences and attribution terms. Read the project disclaimer.

Conservation status references

Automated IUCN and IUCN-derived category lookup is disabled until applicable permission is confirmed. The Atlas does not request IUCN assessment categories from the IUCN API, GBIF’s category endpoint, or iNaturalist status fields. Users can open the IUCN Red List ↗ themselves; that manual link does not mean the Atlas downloads or stores assessment data.

Use and interpretation disclaimer. This is a free-to-access, independent exploratory tool. The data may be incomplete, outdated, misidentified or spatially imprecise; missing observations do not prove a species is absent. Neither the grid nor an occurrence point should be interpreted as a confirmed habitat, full distribution range, conservation status, or protected-area boundary. Check the original records, attribution and licence before reusing data. The software licence applies to the code and does not override third-party data terms.
